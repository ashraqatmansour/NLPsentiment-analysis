# Sentiment Analysis Tool (Python)

## Overview

This project implements a simple sentiment analysis pipeline in Python.  
It processes text files containing user comments, loads a sentiment dictionary from a pickle file, computes sentiment frequencies for each comment, and determines the overall sentiment polarity.

The system supports three sentiment categories:
- POSITIVE
- NEGATIVE
- NEUTRAL

This project is suitable for basic text processing and sentiment classification tasks in an academic or learning context.
